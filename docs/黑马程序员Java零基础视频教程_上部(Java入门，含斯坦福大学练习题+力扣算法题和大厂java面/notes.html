任意进制转十进制：系数乘基数的权次幂

⏱ 20:22 – 30:10

问题

  • ?进制之间能互相转化吗？
  • ?如何将任意进制转为十进制？

步骤

  1. 确定系数（每一位上的数字）、基数（当前进制）、权（从右往左从0开始递增）。
  2. 计算每一位：系数 × 基数^权。
  3. 将所有结果相加得到十进制数。
  4. 记住二进制每一位对应的十进制值：从右往左依次为1,2,4,8,16,32,64,128,...。
  5. 将二进制中为1的位对应的值相加。

要点

  • •系数：每一位上的数字。
  • •基数：当前进制数。
  • •权：从右往左依次为0,1,2,...。
  • •二进制101转十进制：1×2^2 + 0×2^1 + 1×2^0 = 5。
  • •八进制101转十进制：1×8^2 + 0×8^1 + 1×8^0 = 65。
  • •十六进制ABC转十进制：10×16^2 + 11×16^1 + 12×16^0 = 2748。
  • •二进制位值：1,2,4,8,16,32,64,128,...。
  • •二进制1101转十进制：8+4+1=13。

结论

任意进制转十进制使用公式：系数×基数^权，再求和。 8421法可快速将二进制转为十进制，只需将1对应的位值相加。

十进制转任意进制：除基取余法

⏱ 30:10 – 34:26

问题

  • ?如何将十进制转为其他进制？

陷阱 / 误区

  • !有些资料除到商为1就停止，但正统解法应除到商为0。

步骤

  1. 用十进制数不断除以目标进制数（如2），记录余数。
  2. 重复直到商为0。
  3. 将所有余数从下往上拼接得到结果。

要点

  • •十进制11转二进制：11÷2=5余1，5÷2=2余1，2÷2=1余0，1÷2=0余1，结果1011。
  • •十进制7转二进制：7÷2=3余1，3÷2=1余1，1÷2=0余1，结果111。

结论

十进制转其他进制使用除基取余法，直到商为0，余数倒序拼接。

  • !不要以为声音直接存储，而是通过采样点记录。

步骤

  1. 对声音波形图进行采样，每个采样点对应一个数字。

要点

  • •声音波形图上的每个点都有数字对应。
  • •高音质=更多采样点，低音质=更少采样点。

结论

声音通过采样波形图并记录数字来存储，采样密度决定音质。
