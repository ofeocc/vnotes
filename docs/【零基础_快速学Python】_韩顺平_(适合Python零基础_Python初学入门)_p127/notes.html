问题

  • ?如何注解函数的返回值？
  • ?函数类型注解不匹配时也会警告吗？
  • ?类型注解是强制性的吗？

陷阱 / 误区

  • !返回值注解使用箭头->类型。
  • !参数注解在参数名后加冒号和类型。
  • !类型注解只是提示，不是强制，程序仍可运行。

步骤

  1. 参数注解：def func(param: type):。
  2. 返回值注解：def func() -> type:。
  3. 例如：def add(a: int, b: int) -> int: return a + b。
  4. 调用时如果传入类型不匹配，IDE给出黄色警告。
  5. 即使有警告，程序仍可运行，但可能出错。

要点

  • •参数注解：参数名: 类型。
  • •返回值注解：-> 类型。
  • •类型不匹配时IDE给出黄色警告。
  • •注解是提示性的，不是强制性的。
  • •程序仍可运行，但逻辑错误可能导致异常。

结论

函数参数和返回值可以使用类型注解，类型不匹配时给出黄色警告，但注解只是提示，不是强制。

详细讲解展开本章完整拆解
变量联合注解

a: Union[int, str] = 10，如果赋值为float则警告。

容器联合注解

my_list: List[Union[int, str]] = [1, 'a']，元素可以是int或str。

函数联合注解

函数参数和返回值可以使用Union，例如def func(a: Union[int, str]) -> Union[int, str]。

问题

  • ?什么是联合类型注解？
  • ?如何使用Union类型？
  • ?联合类型注解在变量、容器、函数中如何使用？
  • ?联合类型不匹配时也会警告吗？

陷阱 / 误区

  • !使用Union需要从typing导入。
  • !Union可以指定多个类型，用逗号分隔。
  • !类型不匹配时警告。

步骤

  1. 导入Union：from typing import Union。
  2. 变量注解：a: Union[int, str] = 10。
  3. 容器注解：my_list: List[Union[int, str]] = [1, 'a']。
  4. 函数参数注解：def func(a: Union[int, str]):。
  5. 函数返回值注解：def func() -> Union[int, str]:。
  6. 如果赋值的类型不在Union中，给出黄色警告。

要点

  • •需要从typing导入Union。
  • •语法：Union[类型1, 类型2, ...]。
  • •可用于变量、容器、函数参数和返回值。
  • •类型不匹配时IDE给出黄色警告。

结论

联合类型注解使用Union指定多个允许的类型，类型不匹配时给出黄色警告。
